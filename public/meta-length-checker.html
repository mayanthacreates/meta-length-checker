Frequently asked questions

How long should a meta title be?

Keep the title under roughly 580 pixels on desktop - usually 50 to 60 characters. Wider than that and Google cuts it mid-thought with an ellipsis, which costs clicks. Pixel width is what matters: wide letters like W and M use up the budget faster than narrow ones.

How long should a meta description be?

Aim for about 920 pixels on desktop - typically 150 to 160 characters. Mobile allows a little more. Google rewrites descriptions it doesn’t like, but a tight, relevant description within the limit is far more likely to be shown as written.

Why measure pixels instead of counting characters?

Google truncates snippets at a fixed pixel width, not a character count. “Illinois” and “WWDC 2026” are both 8-9 characters but render at very different widths. Character counters are a rough proxy; this tool measures the actual rendered width using Google’s SERP font metrics.

Do desktop and mobile have different limits?

Yes. Desktop titles render at Arial 20px with roughly a 580px limit; mobile titles are smaller but wrap across a wider block, so about 920px fits. Descriptions get around 920px on desktop and 1300px on mobile. The device toggle applies the right metrics for each.

Will Google always show my meta description?

Not always - Google generates its own snippet for around a third of results when it thinks page content answers the query better. You still control the default, and a well-written description within the pixel limit is used most of the time.
